# Ersen Atan Eğitim — Masaüstü Uygulaması

Ersen Atan Eğitim Kurumları öğrenci, veli ve öğretmen uygulamasının Windows sürümü.
Ders programı, deneme sonuçları, ödevler, etüt randevuları ve duyurular tek yerde.

## İndir

**[Windows için indir](https://github.com/CaffeAddiction/ersen-atan-egitim-indir/releases/latest/download/ErsenAtanEgitim-Kurulum.exe)**
— Windows 10 ve 11 (64 bit), yaklaşık 95 MB

Diğer cihazlar:

- **Android telefon ve tablet:** [Google Play](https://play.google.com/store/apps/details?id=com.ersenatan.egitim)
- **iPhone, Mac, Linux:** [web sürümü](https://ea-egitim.web.app)

## Kurulum

1. İndirilen `ErsenAtanEgitim-Kurulum.exe` dosyasını açın. Kurulum kendiliğinden tamamlanır ve
   uygulama açılır; masaüstüne kısayol eklenir. Yönetici izni gerekmez.
2. Windows “Windows kişisel bilgisayarınızı korudu” uyarısı gösterirse **Ek bilgi** →
   **Yine de çalıştır** seçeneğini kullanın.
3. Kurumumuzun size verdiği **kullanıcı adı ve şifreyle** giriş yapın. Hesabınız yoksa
   şubemizle iletişime geçin.

## Sık sorulanlar

**Güncelleme nasıl yapılır?** Uygulama her açılışta güncel sürümü yükler; yeniden kurmanız gerekmez.

**İnternet gerekli mi?** Evet. Uygulama internet bağlantısı ile çalışır.

**Nasıl kaldırılır?** Windows Ayarlar → Uygulamalar → “Ersen Atan Eğitim” → Kaldır.
